# Zen's Missing Hotkeys

Keyboard shortcuts for the tab actions Zen doesn't bind out of the box.

</div>

## Hotkeys

- **Close tabs below** — closes every tab below the active one
- **Close other tabs** — closes all tabs except the active one

All hotkeys are **unbound by default**. Open the mod's settings, click a field,
and press the combination you want — it records instantly and warns you if it
clashes with an existing browser/Zen shortcut (or another hotkey in this mod).
Press `Del` in a field to clear it.

> [!NOTE]
> Pinned and hidden tabs are never touched.
